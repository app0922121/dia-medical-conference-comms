# 模拟测试与盲评记录

日期：2026-11-14。均为合成会议资料，不是真实会议或医学事实。

## 方法

用6条相同请求比较完整rc1与rc2候选包。每组为新开的独立执行代理，不继承项目聊天；组内6条共用一个会话。两组只看输入和自己的Skill文件，不能读预设检查项或另一组输出。外部Humanizer-zh单独跑3条适用的已有文本编辑任务；不让它承担其范围外的会议资料生成。

实际运行读取了两个完整包的按需参考文件，解决上一轮只给旧主文件的比较偏差。主代理提前保存inputs及checks，生成后删除执行记录、路径、版本与写作块ID，留下实际回复。两位新代理各读相反的X/Y顺序作独立模拟编辑评价：judge-1中X=rc2，judge-2中Y=rc2。评委不知版本。

这不是真人评测，不是跨模型复现，不是统计实验。所有执行器均由同一宿主代理体系提供；没有凭空填写底层模型版本或运行成本。没有AI检测器，也没有将模型自评分称为质量证据。写稿、评分代理有相同模型家族偏差的可能。

## 结果

| 场景 | 两位评委一致的相对判断 | 依据 |
|---|---|---|
| 多模块长稿 | rc2略好，但均需修 | rc1无依据用“她”指林澈；rc2保留时间来源、少重复，但把没标准答案扩大成没有统一结论 |
| 轻度去空话/保护引语与批准段 | rc2略好 | 两者保护引语；rc2保留有信息的主题句，rc1将主题与空话一起删去 |
| 合格原稿只审不改 | 平 | 均允许零修改 |
| 计划讲者缺席/他人代读 | 平 | 均保留实际情况与来源冲突，未补职务或共识 |
| 会前预告/未公开讲者 | rc1略好 | 两者保密与时态正确，rc2有一句重复预告 |
| 缺资料仍要求具体细节 | 平 | 均未靠常识编现场内容 |

两位评委均选rc2整体小幅领先，但发现其事实边界错误，不能把相对胜出当交付质量通过。2胜/1负/3平只是这组任务的偏好结果，不是“提升百分比”。

外部Humanizer-zh三条输出在引语/确认段、零修改、缺材料不编造方面也守住边界；没有证据表明rc2在这三项上优于它。其protected输出保留“第一段/第二段（已批准）”标签，直接发布前需去掉编辑标记。DIA包的价值在于完整会议流程，不是所有句子都比单一编辑工具写得好。

## 修订与复测

根据两位评委一致指出的证据问题，在rc2/evidence.md补充通用规则：资料未记录不等于事件未发生；不能从姓名推断性别、身份或动机；编辑连接也不能补事实。没有为林澈这个名字单独打补丁。

复测包括原长稿，以及新的“纪要未载投票/观众提问，结果稍后整理”案例。输入输出保存在retest-inputs.json与retest-output.md。主代理已回读两条实际输出：原长稿未再给林澈添加性别，模块四只写主持未提供标准答案，没有推断统一结论；新案例保留“纪要未载明是否投票/未记录观众提问”，未改成“未投票/无人提问”，也未补顾晨性别。两项目标问题本次未复现。复测未再做两位独立盲评，也未重跑全部六题，不能声称全面稳定。

## 剩余边界

不能证明世界最佳，也不能证明长期稳定提升。尚缺跨模型、多轮重复、真实负责人盲选、实际速记误识别与复杂图片测试、耗时成本对比。未获得真实PV资料，但用户已同意本轮用模拟材料测试；这不等于真实发布授权。
