# 清禾药物安全工作交流会第二日：核对附件差异，厘清来源记录

*本文依据合成会议材料撰写，会议、机构及人物均为虚构。*

2026年11月13日，清禾药物安全工作交流会第二日活动在杭州举行。当天的交流涉及重复附件检查、来源记录管理及模拟案例讨论。模块二与模块三并行开展，分别呈现附件核查与记录对应的方法；模块四则通过同一报告的两个版本，让小组比较差异、列出疑点，并讨论求证对象。

在周苒主持的模块二中，清禾研究中心资料管理负责人陈宁演示了重复附件检查流程：系统标记候选后，由工作人员核对，再决定是否合并。“先核对，再合并。”陈宁用这句话说明处理顺序。这一做法仅在附件格式一致时试用，尚无处理用时统计，现有演示不能说明节省了多少时间。

清禾研究中心质量专员林澈提醒，两份附件即使内容接近，也可能分别包含补充信息。系统给出的标记不能替代人的判断。她提出的这一限制，与演示中的人工核对环节直接相关：内容相似，仍需核查其中是否存在不能遗漏的信息。

在同期由杜岚主持的模块三中，杉木信息团队分析师叶青展示了文件版本号、接收日期与处理记录之间的对应关系。此次演示限于记录管理，不涉及药品安全性的因果判断。讨论中，对于应先统一字段，还是先明确责任，现场出现了不同意见；记录未能识别发言者，也没有显示讨论形成一致结论。

模块四由宋禾主持，采用模拟案例开展小组讨论。各组收到同一报告的两个版本，后一个版本补充了一项日期。小组先比较两个版本的差异、列出疑点，再讨论应向谁求证。主持人未提供标准答案，材料也没有给出最终处理决定。

这一案例把版本差异和求证对象放进了同一个讨论情境，但其用途止于模拟练习，不代表真实患者情况或药品结论。当天的记录保留了具体操作方法，也留下了尚未解决的问题：字段与责任如何安排先后，仍有不同意见；附件合并则须在既定试用条件下经过人工核对。
:::

核查说明：依据所给议程A及现场S1—S3核对人物、角色和内容；模块二、三按并行关系处理，未重复首日报告收集内容。直接引语原样保留，未将匿名讨论归给讲者或写成共识。认可样段仅用于组织写法。未提供照片，未做图文核查及手机预览；稿件待负责人审阅。
