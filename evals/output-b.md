# 从附件核查到版本求证：清禾药物安全工作交流会第二日回顾

2026年11月13日，清禾药物安全工作交流会在杭州举行第二日活动。当天的交流涉及重复附件核查、来源记录和模拟案例中的版本比较。讲者分别介绍了系统标记与人工核查如何衔接、不同记录如何对应；讨论也留下了尚未解决的问题：字段统一与责任明确，应当先推进哪一项？

模块二与模块三在议程中安排于09:00—10:00并行进行。由周苒主持的模块二中，清禾研究中心资料管理负责人陈宁演示了重复附件检查：系统先标记候选，再由工作人员核查，决定是否合并。陈宁说：“先核对，再合并。”这项做法仅在附件格式一致时试用，目前尚无处理用时统计，不能据此判断是否缩短了处理时间。

清禾研究中心质量专员林澈提醒，两份内容接近的附件，仍可能分别包含补充信息。因此，候选标记不能替代人工判断。陈宁介绍的操作步骤与林澈提出的提醒，共同指向核查时需要保留的区别：发现内容相近，并不等于已经具备合并依据。

杜岚主持的模块三讨论来源记录。杉木信息团队分析师叶青展示了文件版本号、接收日期与处理记录之间的对应方式，并明确此次演示限于记录管理，不讨论药品安全性因果判断。讨论中，一种意见主张先统一字段，另一种意见认为应先明确责任。现场记录未能识别两种意见的发言者，也未记录一致结论。

议程安排于10:20—11:30的模块四采用模拟案例，由宋禾主持。各小组收到同一报告的两个版本，后一个版本补充了一项日期。小组先比较差异、列出疑点，再讨论应向谁求证。宋禾没有提供标准答案；这一环节保留了从发现信息变化到确定求证对象的讨论过程，未将练习收束为统一处理结论。案例属于模拟情境，不代表真实患者情况或药品结论。
