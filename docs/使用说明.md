# DIA宣发Skill v2.0.0-rc2

本候选版保留会前计划、报名推文、会中快讯、会后通稿与局部改稿。只在现有编辑步骤补“表达审校”，没有另加自动发布或全篇洗稿功能。

## 核心变化

- 先保护事实、归属、限定、时态、直接引语和已确认措辞，再调整表达。
- 删除无信息重复，重组割裂段落；不把常用词或标点当禁用项。
- 原稿合格允许零修改，局部任务不扩改全文。
- 按会前/会后/服务通知调整语气，保持DIA专业中立底色。
- 修后回原始材料查语义，不用流畅掩盖缺证。

## 试用

提供完整目录，并明确要求助手读取SKILL.md及该任务引用文件。可说：“按这套DIA宣发Skill，根据这些议程、速记与认可范文写第二日通稿；完成后检查表达和事实，待核事项单列。”

文件夹不是独立App。运行需能读取本地或上传文件的助手；不同宿主如何发现/安装Skill需另核实。本次未安装、未替换全局配置；不要把收到文件包等同于已启用。

## 测试及限制

本轮6个合成用例用于现版与候选版对照，3个编辑用例也交公开Humanizer-zh处理；独立模型盲评不等于真人编辑认可。具体结果见同包《模拟测试结果.md》。所有人物、机构与案例为虚构，不用于真实药品判断。

“世界最好”作为高标准目标，不作为已验证宣传。当前未验证真实完整PV素材、跨模型、多轮重复、自动触发、手机图文和传播转化。旧rc1仍保留用于比较。

## 文件

SKILL.md是入口，references按任务读取，assets/work-record.md为内部记录模板。REFERENCES.md说明设计参考与使用范围。SHA256.json用于检查文件一致性，不代表写作质量。
