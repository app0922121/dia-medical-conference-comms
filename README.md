# DIA 医药会议宣发 Skill

当前版本：**v2.0.0-rc2**（候选版）。用于会议宣发计划、会前公众号文案、会中快讯、会后通稿和局部编辑。

根据认可范文组织写法，核对人物与来源；表达审校保留事实、归属、限定、时态、直接引语和已确认措辞。原稿合格时允许不修改。不以AI检测分数判断质量。

## 使用

将完整的 `dia-medical-conference-comms/` 目录提供给能读取文件的助手，要求读取 `SKILL.md`，按任务打开对应参考文件。例如：

> 按这套DIA宣发Skill，根据这些议程、速记和认可范文写第二日通稿。正文之外列出待核事项。

[使用说明](docs/使用说明.md) · [Skill入口](dia-medical-conference-comms/SKILL.md) · [设计参考](dia-medical-conference-comms/REFERENCES.md)

本仓库不自动安装，不代表宿主已启用或自动触发成功。

## 验证范围

已执行六类合成用例的新旧版对照、三类外部编辑Skill比较、两位模型顺序交换盲评及两项针对性复测。材料均为合成，不是真实会议或医学事实。

新版在该组测试中有有限优势，也暴露了需修正的证据推断错误。不能据此声称世界最佳、跨模型稳定、医学合规或获准发布。

## 文件与版本

- `dia-medical-conference-comms/`：完整运行技能。
- `docs/`：使用说明。
- `evals/`：合成测试及实际输出；本机绝对路径已改成可移植标记，写作内容保留。
- `dist/`：仅含运行技能的版本包及内容校验清单。

技能文件与本地rc2候选逐字一致。Git标签 `v2.0.0-rc2` 标识本次上传。

## 使用边界

私人维护的编辑辅助工具，非DIA官方发布或授权背书。范文片段来自用户提供材料，仅用于内部评估；公开分发前需确认相关权利。本仓库未授予额外的开源许可。研究参考不代表其作者对本项目认可。

未经负责人实际审阅，不将生成稿标成可直接发布；不自动上传会议资料或发布公众号。真实完整资料、人工风格验收、手机图文与长期效果仍待验证。
